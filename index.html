Clean up storage space on your Mac

A straightforward, independent guide to finding what is using disk space and safely managing files, applications, downloads, backups, and other storage categories.

Important:This website provides educational information only. It does not distribute, install, or download desktop software.

Start with these simple steps

Use the storage tools already available on your Mac. Before deleting anything, review important files and keep a backup of data you may need later.

1

Check storage usage

Open your Mac's storage settings to see which categories are using the most disk space. This helps you decide where cleanup will have the greatest effect.

2

Review large files

Look through Downloads, videos, installers, archives, and other large files. Remove only items you no longer need.

3

Empty the Trash

Items moved to the Trash can continue to occupy disk space until the Trash is emptied. Confirm that you do not need those files first.

Mac storage cleanup checklist

1

Review Downloads

Remove old installers, duplicate files, archives, and other downloads that you no longer need.

2

Remove unused applications

Review applications you no longer use and uninstall them using the normal macOS process. Check associated data before removing anything important.

3

Move large personal files

Consider moving large photos, videos, project files, or archives to another storage device when appropriate.

4

Review old backups

Check whether old device backups or duplicate copies are still required before deleting them.

5

Empty the Trash

After reviewing deleted files, empty the Trash if you are certain you do not need to restore anything from it.

Helpful storage habits

Keeping storage organized regularly can make it easier to avoid running out of disk space.

Keep clean space available

Try not to let the startup disk remain nearly full for long periods. Regularly review large and temporary files.

Use a backup

Maintain an appropriate backup before performing major cleanup. A backup can help protect files that you accidentally remove.

Clean up regularly

A short monthly review of downloads, large media files, and unused applications can prevent storage from becoming difficult to manage.
